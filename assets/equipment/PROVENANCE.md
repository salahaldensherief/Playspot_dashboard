# Equipment artwork provenance

The seven equipment-*.svg files in this directory were authored as original SVG geometry for PlaySpot in this change. They contain neutral equipment, no third-party logos, screenshot pixels, embedded fonts, scripts or remote references. No stock artwork was downloaded or incorporated; there is no stock-asset attribution requirement. These are project assets, not a grant to redistribute an external asset library.

Rendering uses the existing flutter_svg 2.3.0 dependency under its MIT license (https://pub.dev/packages/flutter_svg/versions/2.3.0/license). Preserve the dependency's license notices. Do not infer device capability or vendor support from an illustration.
